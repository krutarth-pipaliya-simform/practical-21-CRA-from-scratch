## Steps to perform.

1. This will ask you some basic information about your project and initialise package.json.
    ```bash
        npm init
    ```
2. install react and react-dom.
    ```bash
        npm i react
        npm i react-dom
    ```
3. install webpack, webpack-cli, webpackpdev-server, html-webpack-plugin as dev dependencies.
    ```bash
        npm i -D webpack
        npm i -D webpack-cli
        npm i -D webpack-dev-server
        npm i -D html-webpack-plugin
    ```
4. install babel as dev dependency.
    ```bash
        npm i -D @babel/core
        npm i -D babel-loader
        npm i -D @babel/preset-react
        npm i -D @babel/preset-env
    ```
5. install TS, types of react and react-dom as dev dependecies.
    ```bash
        npm i -D typescript
        npm i -D @types/react
        npm i -D @types/react-dom
        npm i -D @babel/preset-typescript
    ```
