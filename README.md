## Steps to perform.

1. This will ask you some basic information about your project and initialise package.json.
    ```bash
    npm init
    ```
2. install react and react-dom
    ```bash
    npm i react
    npm i react-dom
    ```
3. install webpack, webpack-cli, webpackpdev-server as dev dependency
    ```bash
    npm i -D webpack
    npm i -D webpack-cli
    npm i -D webpack-dev-server
    ```
